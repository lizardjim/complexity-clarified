## Testing the CMS

This is a test article designed to make sure the **Complexity Clarified CMS** is handling Markdown correctly.

It includes *italic text*, **bold text**, and punctuation that shouldn't cause any problems: colons, apostrophes, "quotation marks", question marks and dashes.

> ***If this appears as a styled callout, the Markdown rendering is working correctly.***

## A Second Heading

The CMS should preserve the structure of the article when it is saved as a draft and subsequently reopened.

There are three things we're testing:

- Markdown is saved correctly
- Frontmatter remains valid
- The article can be reopened without losing content

### One More Level

We can also test a numbered list:

1. Create the article
2. Save it as a draft
3. Reopen the draft
4. Check the title, description and article body
5. Publish it if everything looks correct

And finally, here's a sentence containing some deliberately awkward punctuation:

**Does "Minimum Viable Human: The Change Management Metric Nobody Measures" still work?**

If it does, we're done.
